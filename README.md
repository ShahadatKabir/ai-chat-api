# AI Chat API (.NET + Gemini)

## 🚀 Requirements
- .NET 10 SDK installed

---

## ✅ New Features
- JWT login endpoint for issuing tokens
- Protected `api/chat` endpoint for Gemini-based chat
- In-memory chat history support via `api/chat/history`
- Configurable Gemini API key from `appsettings.json` or `GEMINI_API_KEY`
- Swagger UI with Bearer auth support
- Health endpoint at `api/test/health`
